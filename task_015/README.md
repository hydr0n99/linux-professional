# Настройка мониторинга

## Цель

Научиться настраивать дашборд

## Описание/Пошаговая инструкция выполнения домашнего задания:

Настроить дашборд с 4-мя графиками

* память
* процессор
* диск
* сеть

Настроить на одной из систем:

* zabbix (использовать screen, комплексный экран)
* prometheus - grafana

# Выполнение

В качестве хоста использовалась ВМ под управлением Ubuntu 24.04. В соответствии с инструкциями в презентации были установлены следующие компоненты:

* Prometheus Enterprise 3.5.4
* Prometheus Node Exporter 1.11.1 
* Grafana Enterprise 13.0.2

Dashboard был выбран с ID `1860` (Node Exporter Full). Скриншот развёрнутого dashboard лежит [тут](./dashboard.png). Имя указано в названии.
