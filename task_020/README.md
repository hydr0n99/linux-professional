# Настройка PXE сервера для автоматической установки

## Цель

Отработать навыки установки и настройки DHCP, TFTP, PXE загрузчика и автоматической загрузки.

## Описание/Пошаговая инструкция выполнения домашнего задания:

### Дано

Что нужно сделать?

1. Настроить загрузку по сети дистрибутива Ubuntu 24
2. Установка должна проходить из HTTP-репозитория.
3. Настроить автоматическую установку c помощью файла user-data

## Выполнение

В качестве хоста используется ВМ под управлением Ubuntu 24.04 с 24 ГБ RAM на борту и вложенной виртуализацией.

## Дополнительная информация

Вообще говоря, установка ОС происходит циклично: после окончания установки и перезагрузки процесс начинается заново. Это связано с тем, что первым приоритетом загрузки в Vagrantfile указано "net". Логика подсказывает, что нужно первым пунктом ставить "disk", а уже потом "net", чтобы при отсутствии возможности загрузки с диска (т.е. отсутствии системы в принципе) происходила установка по сети, а уже после установки система грузилась с диска. Однако "пустого" box'а для Vagrant я не нашёл (возможно, плохо искал), чтобы такой подход сработал, поэтому какая-то система по умолчанию у ВМ будет. Выход из данной ситуации нашёл такой:

1. После окончания установки и перезагрузки, когда заново начинается загрузка linux и initrd, остановить машину полностью.

2. Убрать SSH forwarding: для этого надо удалить правило с помощью команды

```
VBoxManage modifyvm "$(cat .vagrant/machines/pxeclient/virtualbox/id)" --natpf1 delete ssh
```

и также отключить стандартный SSH-проброс от Vagrant (раскомментировать строки конфигурации клиента в [Vagrantfile](./Vagrantfile)).

3. Изменить первый приоритет запуска с "net" на "disk" (см. [Vagrantfile](./Vagrantfile)).

Затем, позвав `vagrant up pxeclient`, откроется окно VirtualBox, в котором можно увидеть загрузку системы, и затем войти в неё с логином `otus` и паролем `123`, т.е. система установлена и работает.

P.S. По какой-то причине не всегда удаётся запустить стенд корректно (клиент выдаёт timeout при попытке первичной загрузки по сети или соединение прерывается при загрузке ISO-образа через wget). При первом запуске после включения хоста (тоже ВМ), однако, всегда всё отрабатывает стабильно (5 раз проверял). Но при повторном создании/удалении машин время от времени наблюдается описанное поведение. Предполагаю, что проблема во вложенной виртуализации и/или каких-то особенностях Vagrant.
