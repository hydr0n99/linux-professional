# Репликация и бэкап PostgreSQL

## Цель

Настроить потоковую репликацию PostgreSQL со слотами и реализовать корректное резервное копирование для обеспечения отказоустойчивости сервиса.

## Описание/Пошаговая инструкция выполнения домашнего задания:

* Настроить hot_standby репликацию с использованием слотов
* Настроить правильное резервное копирование

## Выполнение

В качестве хоста используется ВМ под управлением Ubuntu 24.04 с 24 ГБ RAM на борту и 6 ядрами, а также вложенной виртуализацией.
