## Описание/Пошаговая инструкция выполнения домашнего задания:

* установите Docker на хост машину https://docs.docker.com/engine/install/ubuntu/

* определите разницу между контейнером и образом
* вывод опишите в домашнем задании.
* ответьте на вопрос: Можно ли в контейнере собрать ядро?

## Ответы на вопросы из задания:

**1. Определите разницу между контейнером и образом**

Контейнер - по сути, просто процесс в системе, который использует ресурсы этой самой системы (в первую очередь ядра, разумеется), а в себе хранит лишь минимальные данные, необходимые для запуска целевого приложения.

Образ ВМ - полноценная машина, со своим отдельным ядром (которое ещё может и не совпадать архитектурно с ядром хостовой машины, что для контейнеров вроде бы невозможно). Управляется через гипервизор, потребляет реально выделенный ресурс "железа" (RAM/CPU).

Вывод: Разные инструменты для разных задач: ВМ - тяжеловесная, но полностью изолированная среда; контейнер - легковесный процесс с самым необходимым.

**2. Можно ли собрать в контейнере ядро?**

Можно, но использовать его не получится ввиду описанного выше.
